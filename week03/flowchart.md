# 第3回 フローチャート集（プログラムの基本構造）

講義スライドのフローチャートを、ブラウザで見られる形にまとめたものです。
対応するPythonの例題は [examples/](examples/) にあります。

| 記号 | 名前 | 意味 |
| --- | --- | --- |
| 角の丸い長方形 | 端子 | 開始・終了 |
| 長方形 | 処理 | 何かを行う |
| 平行四辺形 | 入出力 | データを入れる・表示する |
| ひし形 | 判断 | 条件で道が分かれる（出る線に「はい／いいえ」を書く） |

## 1. 順次処理（[sequence.py](examples/sequence.py)）

書かれた順に、上から1つずつ実行する。

```mermaid
flowchart TD
    S([開始]) --> A[お湯を沸かす] --> B[お湯を注ぐ] --> C[3分待つ] --> D[食べる] --> E([終了])
```

## 2. 分岐（[branch.py](examples/branch.py)）

条件によって、実行する処理を選ぶ。どちらの道を通っても、最後は1つに合流する。

```mermaid
flowchart TD
    S([開始]) --> I[/点数を入力/] --> Q{60点以上？}
    Q -- はい --> P[/「合格」と表示/]
    Q -- いいえ --> F[/「不合格」と表示/]
    P --> E([終了])
    F --> E
```

## 3. 繰り返し（[loop.py](examples/loop.py)）

「何をくり返すか」と「いつ止めるか」をセットで考える。

```mermaid
flowchart TD
    S([開始]) --> Z[回数を 0 にする] --> Q{回数は10未満？}
    Q -- はい --> A[スクワットを1回する] --> B[回数に 1 を足す] --> Q
    Q -- いいえ --> E([終了])
```

## 4. 3つの構造の組み合わせ（[combined.py](examples/combined.py)）

繰り返しの中に分岐が入っている（入れ子）。

```mermaid
flowchart TD
    S([開始]) --> L{まだ判定していない人がいる？}
    L -- はい --> I[/次の人の点数を入力/] --> Q{60点以上？}
    Q -- はい --> P[/「合格」と表示/] --> L
    Q -- いいえ --> F[/「不合格」と表示/] --> L
    L -- いいえ --> E([終了])
```

## 5. 例題：自動販売機でジュースを買う

| 手順書 | 構造 |
| --- | --- |
| 1. お金を入れる | 順次 |
| 2. 合計が足りなければ、1に戻る | 繰り返し |
| 3. 商品のボタンを押す | 順次 |
| 4. おつりがあれば、おつりを出す | 分岐 |
| 5. 商品を出す | 順次 |

```mermaid
flowchart TD
    S([開始]) --> M[お金を入れる] --> Q1{合計 ≧ 価格？}
    Q1 -- いいえ --> M
    Q1 -- はい --> B[ボタンを押す] --> Q2{おつりがある？}
    Q2 -- はい --> C[おつりを出す] --> G[商品を出す]
    Q2 -- いいえ --> G
    G --> E([終了])
```

手順書の「〜なら」「〜があれば」は分岐、「〜まで」「戻る」は繰り返しの合図です。
