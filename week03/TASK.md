# A03：身近な処理を「入力・処理・出力」と手順書で書く

- 配布：第3回（10/16）　締切：10/22（木）23:59
- 提出物：このフォルダの `answer.md`
- 配点：2点（0：未提出／1：提出したが説明不足／2：3つの構造が正しく使われ、他の人が読んで手順を再現できる）

## 課題

身のまわりの処理を1つ選び（例：自動販売機でおつりを出す、電車の運賃を決める、洗濯機のコースを選ぶ）、`answer.md` に次を書いてください。

1. その処理の入力・処理・出力
2. 日本語の手順書（1行に1つの動作。順次・分岐・繰り返しのうち2つ以上を使う）
3. 手順書のどの行が順次・分岐・繰り返しにあたるか

プログラムは書きません。第1回のノート代金の例と、今回のスライドの手順書の書き方を参考にしてください。
