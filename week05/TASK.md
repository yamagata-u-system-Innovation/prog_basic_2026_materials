# A05：条件分岐のあるプログラムを書く

- 配布：第5回（10/30）　締切：11/5（木）23:59
- 提出物：このフォルダの `judge.py` と `answer.md`
- 配点：2点（0：未提出／1：実行できない、道が2つ以下、または説明・実行結果が不足／2：正しく動き、条件の表と各行の説明が他の人にも伝わる）

## 課題

1. `judge.py` を「自分で決めた判定」に書きかえる。
   - テーマの例：体温（37.5 以上なら休む）、気温（服装を決める）、年齢（料金区分）、荷物の重さ（送料）、歩数（今日の評価）
   - `input()` と `int()` で値を受け取り、`if` / `elif` / `else` で **3つ以上の道** に分ける。
   - 結果は f文字列で表示する（例：`print(f"{temp} 度なので {advice}")`）。
2. `answer.md` に次を書く。
   - 入力・処理・出力の表
   - 条件の表（値の範囲 → 結果）。範囲に抜けや重なりがないようにする
   - `judge.py` の各行が何をしている行か（1行に1つ）
3. **違う入力で2回以上** 実行し、ターミナルの表示を `answer.md` に貼る。境目の値（「以上」「未満」の切りかわる値）を1つは入れる。

第5回スライドの「仕様として整理する」「境目の値で確かめる」と、教材リポジトリの `week05/examples/judge.py` を参考にしてください。

## 提出のしかた

1. VS Code で `judge.py` と `answer.md` を編集して保存する（Ctrl + S）。
2. ソース管理でメッセージ（例：「A05提出」）を書いて「コミット」→「変更の同期」。
3. ブラウザで自分のリポジトリを開き、`week05/judge.py` と `week05/answer.md` が更新されていることを確認する。
4. 提出前のチェック：▷ で実行できる／実行結果を貼った／Ctrl + F で「（ここに記入）」が残っていない。
