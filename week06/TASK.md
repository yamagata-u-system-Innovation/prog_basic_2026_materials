## 課題

1. `count.py` を「自分で決めた集計」に書きかえる。
   - テーマの例：1〜n の 3 の倍数の個数と合計、7 の倍数、一の位が 3 の数（`i % 10 == 3`）、4 で割って 1 余る数、など
   - `input()` と `int()` で n を受け取り、`for` と `range()` で 1〜n をくり返す。
   - くり返しの中に `if` を入れ、条件に合う数だけ **個数（count）と合計（total）** を増やす。
   - 結果は f文字列で表示する（例：`print(f"3 の倍数は {count} 個、合計 {total}")`）。
2. `answer.md` に次を書く。
   - 入力・処理・出力の表
   - 変数の表（箱の名前・最初の値・くり返しの中でどう変わるか）
   - 小さい n（例：n = 6）のトレース表（i・条件の結果・count・total を 1 周ごとに書く）
   - `count.py` の各行が何をしている行か（1行に1つ）
3. **違う入力で2回以上** 実行し、ターミナルの表示を `answer.md` に貼る。トレース表と同じ n を1つは入れ、トレース表の最後の行と表示が一致することを確かめる。

第6回スライドの「仕様として整理する」「トレース表で確かめる」と、教材リポジトリの `week06/examples/count.py` を参考にしてください。
