# プログラミング基礎 2026（山形大学 工学部 システム創成工学科）

このリポジトリには、講義で使う **例題プログラム** と **課題文** を置きます。

| 置き場所 | 内容 |
| --- | --- |
| WebClass | 講義スライド、出席確認、宿題の報告 |
| このリポジトリ（公開） | 回ごとの例題プログラム `weekNN/examples/` と課題文 `weekNN/TASK.md` |
| あなたの提出箱 `prog_basic_2026_学籍番号`（非公開） | 課題の提出先。課題文と記入様式は毎週ここにも届きます |

## 使い方

- 見るだけで構いません。クローンは不要です。
- ファイル名をクリックすると、ブラウザ上で中身が表示されます。
- 手元に置きたいときは、ファイルを開いて右上の「Download raw file」（下向き矢印）を押します。
